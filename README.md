## О игре
Живой город на Roblox: два города (Южный и Северный), работы, машины с вождением, полиция и штрафы, кафе, электричка и шоссе между городами. В телефоне GorodOS — 18+ приложений: банк, транспорт, курьер, казино, погода, тарифы сотового оператора с настоящим 2G–5G.
